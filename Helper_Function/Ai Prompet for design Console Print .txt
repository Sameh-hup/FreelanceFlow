أنا أعمل على مشروع C# Console Application لمشروع التخرج، وأستخدم مكتبة Spectre.Console لتنسيق الواجهات والطباعة.

المطلوب:
قم بإعادة صياغة وتعديل كافة دالّات الـ UI والـ Menus والطباعة في الكود المرفق لتتبع نفس الستيل والتنسيق الاحترافي التالي بدقة:

1. الـ Menus الرئيسية والفرعية:
   - رسم المنيو باستخدام الـ ANSI Escape Sequences والـ Box-Drawing (`║ ╔ ═ ╚`) بحجم أبعاد ثابت ومحسوب للسطر لمنع انكسار الحدود (Text Wrapping).
   - توحيد نظام ألوان المنيو: عناوين باللون الأصفر، أرقام الخيارات بين أقواس [ ] باللون الأخضر، والنصوص باللون الرمادي/الأبيض، والحدود باللون اللؤلؤي/الساماوي (Cyan).

2. شاشات الإدخال والجداول (Spectre.Console):
   - استخدام `AnsiConsole.Write(new Rule("[yellow]TITLE[/]").RuleStyle("cyan").LeftJustified());` لعناوين الشاشات الفرعية.
   - استبدال كافة عمليات الإدخال التقليدية بـ `AnsiConsole.Ask<T>("[green]Prompt Message:[/] ");` مع مراعاة عدم وضع أي الكلمات غير المعرفة داخل أقواس `[]` لتجنب خطأ الـ Style Not Found.
   - عرض البيانات والقوائم باستخدام `Table` من Spectre.Console مع تفعيل `TableBorder.Rounded` ولون حدود `Color.Cyan1` وبُعد الأوردة التلقائي `table.Expand()`.
   - تغليف كافة رسائل النجاح والخطأ والتحذيرات داخل `Panel` ملونة (Green للنجاح، Red للخطأ، Yellow للتحذيرات) مع رموز الإشارة (`✓`, `✗`, `⚠`).
